# Escape Game Web Sevran 

Projet d'escape game WEB sur le théme de Sevran

## Installation 

Le projet se décompose en trois dossier principal :

-"Apache-php" contient l'ensemble des codes HTML/PHP/CSS/JS
-"bd" contient un fichier backup pour recreer la base SQL 
-"Geoserver-Workspace" contient la carte de chaleur

## Déroulé du jeu 

Le but du jeu est de sortir de la gare de Sevran le plus rapidement possible. Un score initialement à 10000 se décrémentera toute les 30s avant la sortie du jeu.

Les enigmes sont trés simple et suivent direction assez linéaire. 

### 1ére énigme 
Dans un premier temps il faudra apporter la "puff" au guetteur, un vendeur se trouve à l'avenue Jaurés. Une fois la puff remis au getteur celui vous indiquera d'aller voir une 92i à Beau Sevran qui aurait des informations pour sortir de la gare.

### 2e énigme
La 92I vous indiquera d'aller lui checher un "Zedou" à cause d'une erreur d'interprétation. Vous irez allée Jan Masaryk prende un "zedou", le remettre à la 92I permettra d'y voir plus clair sur ses intentions.

### 3e énigme 

Vous devrez aller chercher un shampoing au carrefour de Beau Sevran. La 92I vous remettra le code de la gare à l'issu.

### 4e énigme 

Il faut taper le code (Voir en cliquant dans l'inventaire) en cliquant sur l'image de la gare
